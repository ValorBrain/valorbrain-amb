# Reproducing ValorBrain BEAM-100K Results

## Prerequisites

1. A running ValorBrain engine instance (default: `http://localhost:7438`)
2. A GLM-5.2 API endpoint (any OpenAI-compatible provider)
3. An OpenAI-compatible gateway (for deepseek-v4-flash as judge)

## Step 1: Install the Agent Memory Benchmark

```bash
git clone https://github.com/vectorize-io/open-memory-benchmark.git
cd open-memory-benchmark
pip install -e .
```

## Step 2: Add the ValorBrain provider

Copy the provider files from this repo:

```bash
cp provider/valorbrain.py src/memory_bench/memory/
cp provider/glm.py src/memory_bench/llm/
cp provider/gateway.py src/memory_bench/llm/
```

Register the providers:

In `src/memory_bench/memory/__init__.py`, add:
```python
from .valorbrain import ValorBrainMemoryProvider
# In REGISTRY:
"valorbrain": ValorBrainMemoryProvider,
```

In `src/memory_bench/llm/__init__.py`, add:
```python
from .gateway import GatewayLLM
from .glm import GlmLLM
# In REGISTRY:
"gateway": GatewayLLM,
"glm": GlmLLM,
```

## Step 3: Patch the judge override

The BEAM dataset hardcodes Gemini as the judge. To use a different judge, patch `src/memory_bench/runner.py`:

```python
def _get_judge(self, dataset):
    import os
    override = os.environ.get("OMB_JUDGE_LLM")
    if override and override != "gemini":
        return self._judge  # respect OMB_JUDGE_LLM
    dataset_llm = dataset.default_judge_llm() if hasattr(dataset, "default_judge_llm") else None
    if dataset_llm is not None:
        return GeminiJudge(llm=dataset_llm)
    return self._judge
```

Also patch `src/memory_bench/cli.py` to make the Gemini key check non-fatal:

```python
def _resolve_gemini_key():
    key = os.environ.get("GEMINI_API_KEY") or os.environ.get("GOOGLE_API_KEY")
    if key:
        os.environ["GOOGLE_API_KEY"] = key
    # Non-fatal when using non-Gemini LLMs
```

## Step 4: Run the benchmark

```bash
export VALORBRAIN_URL=http://localhost:7438
export VALORBRAIN_TOKEN=your-valorbrain-token
export VALORBRAIN_BENCHMARK_TENANT_ID=your-tenant-id
export OPENAI_API_KEY=your-gateway-key
export OPENAI_BASE_URL=http://localhost:8201/v1
export GLM_API_KEY=your-zai-key
export GLM_BASE_URL=your-glm-endpoint  # any OpenAI-compatible GLM provider
export GLM_MODEL=glm-5.2
export OMB_ANSWER_LLM=glm
export OMB_JUDGE_LLM=gateway

amb run --dataset beam --split 100k --memory valorbrain --llm glm
```

Results are saved to `outputs/beam/valorbrain/rag/100k.json`.

## Notes

- The ValorBrain provider re-windows large AMB chunks into ~8K-char windows with overlap, matching ValorBrain's production ingest behavior.
- If ValorBrain collections already exist (e.g., `beam-100k-1`), the provider reuses them instead of re-ingesting.
- The consolidation, timeline, and keyed-facts synthetic documents are generated by ValorBrain's `/api/v1/memory/prepare` endpoint and delivered via `funnel.delivered_documents`.
